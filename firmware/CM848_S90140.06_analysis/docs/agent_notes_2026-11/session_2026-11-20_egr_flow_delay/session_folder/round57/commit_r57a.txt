cm848: round 57 stage A - the cruise cluster named from its code, the cruise N/V ratio from e2m 8A0E / 8A0F

The cruise cluster at 0x511ea8-0x513980, read function by function. It had ten unprefixed legacy names (none in
CM550), and three of them were wrong-domain:
- governor_cruise_dualCalc_dispatch -> cm848_runCoolantOverheatDerateMonitors: it runs the coolant overheat minimum
  and aggressive derate monitors.
- engine_coolantTemp_delta_calc -> cm848_calculateCoolantOverheatTemperatureError: e2m 8A72 +0 CT_Derate_Temp_Error,
  setpoint - coolant temperature while the overheat derate is active.
- fuel_demand_timing_initialize -> cm848_initializeRockCycleAndTsc1LostManagement: the boot initializer of the two
  functions just before it in ROM (TSC1 lost management armed and its counter loaded, plus the rock cycle lookup
  cache). Nothing in it is fuel demand or timing.

The cruise state functions, each now returning CRUISE_CONTROL_STATE:
- governor_cruise_baseState_get -> cm848_selectBaseCruiseState: HOLD while engaged, else CANCEL while a resume speed
  is kept, else OFF.
- governor_cruise_standbyState_get -> cm848_selectDeniedCruiseState: the state while cruise is denied.
- the switch handlers -> cm848_selectCruiseStateForSetSwitch / ...ForResumeSwitch / ...ForCoastSwitch (a new press
  gives SET / BUMP_UP / BUMP_DOWN; a held switch gives COAST / ACCELERATE after the hold countdown).
- governor_fuel_mode_initialization -> cm848_initializeCruiseControl (boot).

The ratio functions:
- governor_cruise_rpmRatio_ema -> cm848_filterCruiseEngineToVehicleSpeedRatio.
- cm848_integrateCruiseRpmRatioChange -> cm848_integrateCruiseEngineToVehicleSpeedRatioChange.

The e2m 8A0E / 8A0F "N_V ratio" family (both blocks are in the parameter ID table) moves from cruise_rpm_ratio_* to
cruise_engine_to_vehicle_speed_ratio_*:
- the ratio (8A0F +2), its previous value, the integral (8A0F +0), the integral limit (8A0E +A), the maximum /
  minimum (8A0E +E / +10);
- the integral clear count / level (8A0E +6 / +8, were cruise_steady_debounce_count / cruise_ratio_steady_threshold),
  the steady count, and cruise_engine_speed_previous;
- two type-only rows named: the filter coefficient (8A0E +C) and the filter state.
