cm848: round 55 stage A - the fault manager core named from its code (15 functions)

The fault manager at 0x533aec-0x535344, read function by function. Fourteen unprefixed legacy names (none in CM550),
plus cm848_initFaultManagement, renamed to "initialize" now that it is touched.

Two old names were swapped in meaning. cm848_clearDiagnosticState runs the second alone, or both on a full clear
(request bit 2):
- diag_resetSingleFault -> cm848_clearAllFaultRecords: it clears all 170 status records, the readiness and complete
  bits, the recent DTC list and the freeze frame queue.
- diag_resetAllFaults -> cm848_clearPreviouslyActiveFaults: it clears only the previously active faults, the J1939
  DM3 meaning.

  at fault_auto_clear_warm_up_cycle_count_cal warm-up cycles);

  and the coolant warm state against the freeze frame);
