J2 describer notes (round 93) - orientation findings
====================================================
"ROM table 0x1b4da-0x1b4e9": NOT a table. It is the code of the function at 0x1b4d8 (a chain of jsr abs.l = opcode 4EB9
+ 4-byte target): jsr 0x212b2 / jsr 0x23244 / jsr 0x22070 / jsr 0x230ee / jsr 0x21edc / jsr 0x21070 / jsr 0x420bc / rts.
The hits 0x1b4da / 0x1b4e0 / 0x1b4e6 are the JSR operands. executiveFrameInterruptHandler (0x1b876) calls 0x1b4d8 with
bsr.w in each EVEN phase (20 of the 40 phases) and 0x1b504 in each ODD phase.  The caller scan missed it because two
rows share the name vp44_evenPhaseSchedulerTaskSet (0x1b4d8 and 0x1b62a - the second is a mid-function label inside
periodicTaskSet_fuelDemand's JSR chain); the script's dict kept only the 0x1b62a body.
