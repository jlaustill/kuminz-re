cm848: the rest of the CHP charge flow family, the pumping torque and the exhaust pressure words (e2m)

Label-only (reverse_names.py EQUIVALENT; 49 names, all render; 1
function differs only in declaration order). Every name is resolved by
the ECU's parameter ID table and checked against the code.

Functions:
- cm848_fuelControlMainCalculation -> cm848_calculateChargeFlows (the
  10 ms task: charge flow estimate, delayed EGR flow, fresh air flow)
- cm848_initFuelControlFilterSystem -> cm848_initializeChargeFlows
- cm848_fuelDemandWithLoadCompensation -> cm848_calculateChargeFlowEstimate
  (177D: Rankine temperature, volumetric efficiency, charge mass flow,
  Charge_Flow_Source)
- cm848_fuelDemandErrorCalculation -> cm848_calculateFreshAirMassFlow
  (177B: charge - delayed EGR, filtered; Fresh_Air_Flow_Source)
- cm848_checkFuelSystemFaultFlags / cm848_checkEngineFaultConditions ->
  cm848_calculateDownstreamEgrFlowSource / ...UpstreamEgrFlowSource
  (177F +18 EGR_Flow_Source of each model)
- cm848_initFilterCoefficients -> cm848_initializeEgrFlowEstimate,
  cm848_initFilterTablePointers -> cm848_initializeChargeMassFlowFilter,
  cm848_initFuelDemandBlendPointers -> cm848_initializeFreshAirMassFlowFilter,
  cm848_initFuelFilterDefaults -> cm848_initializePumpingTorqueLookupCache
- phase_group_a_validateEngineSync -> cm848_calculateExhaustPressure and
  cm848_initBoostPressureFaultHandling -> cm848_initializeExhaustPressure
  (e2m 1A5D exhaust pressure post-processing; 10 ms / boot)

Globals:
- the exhaust pressure: boost_pressure_current_raw = exhaust_pressure
  (1A5D +0), fuel_demand_droop_state = exhaust_pressure_source (+2),
  boost_pressure_source_flags = exhaust_pressure_state (+4),
  boost_pressure_synthetic_ema = exhaust_pressure_estimate (1772 +A),
  boost_correction_mode_flags = exhaust_pressure_estimate_state (1772 +8);
  the new row exhaust_pressure_estimate_as_primary_cal (EEPROM 0x468,
  1 on this truck: the estimate is the primary exhaust pressure)
- the EGR model tables (e2m 18E3-18E5 / 193D-193F / 1974-1975 /
  1946 + 1940) and the volumetric efficiency tables (1782 / 1783 /
  1961 / 1962), named <output>_x_axis / _y_axis / _grid / _axis /
  _values (were boost_fuel_* / throttle_* / boost_rpm_scale_* /
  boost_load_* _cal; ROM-copied RAM, so no _cal)
- the pumping torque words (1780 / 1781 / 1954: pumping_torque_maximum
  / _minimum / _multiplier / _offset / _engine_delta_pressure_deadband /
  _minimum_fuel / _without_offset, nominal_engine_delta_pressure(_grid);
  were fuel_demand_blend_* / fuel_demand_*_cal)
- the filters (charge_mass_flow_filter_state, fresh_air_mass_flow_filter_state
  + its 1A0F coefficient; egr_oxygen_fraction_filter_state follows the
  EMA-record convention) and the four 1-D lookup caches

The 0x128a0 plate no longer expands CHP as "charge properties": the
e2m never spells it out.
