flagged fuel_quantity_demand_monitor, which sets fault 388 (e2m 1036 Watchdog_Fueling_Error, "fueling is high when
it should not be").
- The Chrysler e2m block 8A70 lines up at 0x40894c by offset, and each of its four words matches its code use:
  - +0 Watchdog_Duration_Threshold: the on-time sum limit (new row watchdog_fueling_duration_threshold);
  - +2 Watchdog_Fueling_Error_Debounce: the pass limit (watchdog_fueling_error_debounce_limit);
  - +4 Watchdog_Speed_Threshold: the engine speed gate (watchdog_fueling_minimum_engine_speed);
  - +6 Watchdog_Min_Duration_Offset: the per-event offset (watchdog_fueling_minimum_duration_offset, was
    fuel_demand_active_correction_increment).
- 8B3B Watchdog_Coolant_Axis / 8B3D Watchdog_Coolant_Duration_Table are the coolant allowance table
  (watchdog_coolant_duration_adjustment_axis / _values, were fuel_quantity_demand_excess_cold_allowance_*), with its
  lookup result and cache (new rows; they rendered DAT_003fce30 / &DAT_003fce32).
- The working words: watchdog_fueling_duration_offset_sum / watchdog_fueling_debounce_count.
- Functions: cm848_monitorWatchdogFueling (was fuel_quantity_demand_monitor) and cm848_initializeWatchdogFueling
