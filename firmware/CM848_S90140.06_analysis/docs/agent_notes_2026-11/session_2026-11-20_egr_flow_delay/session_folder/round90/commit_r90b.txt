  extended RAM file is 0x80 short (0x8092C2 on at file offset 0x80; 0x8091C2-0x8092C1 uncertain).
- test_e2m_name_audit.py: the reader across CM848's gap (before, in, after, signed, across), CM550's extended RAM shift
  and EEPROM, the description words.
