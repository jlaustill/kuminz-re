cm848: round 16 stage A - the cruise control / road speed governor family from e2m 117D-1191 (label-only)

The ECU's parameter ID table places e2m 117D / 117F / 1180 / 1184-1191 / 11A4-11A6; each record was
checked against its code use and its width (59 records, all widths match).

- The road speed governor is road_speed_governor_*: the e2m calls it RSG (Road_Speed_Governor_Enable),
  and its siblings in FUELING_STATE are the low / high / variable / all speed governors.
  FUELING_STATE_VEHICLE_SPEED_LIMIT -> FUELING_STATE_ROAD_SPEED_GOVERNOR, the vehicle_speed_limit_*
  rows and cm848_calculateVehicleSpeedLimitFueling / cm848_presetCruiseAndVehicleSpeedLimitGovernor /
  cm848_runCruiseAndVehicleSpeedLimitGovernor follow.
- The maximum road speeds pair with their trims: maximum_road_speed (was j1939_cruise_speed_setpoint;
  PGN 65261 SPN 74) / maximum_road_speed_trim_cal / cruise_maximum_road_speed_trim_cal;
  road_speed_governor_reference_speed (was cruise_speed_limit_working) = the trim lowered by the fault
  ramp; cm848_calculateMaximumRoadSpeeds (was cm848_calculateFaultCruiseSpeedLimit).
- The PID: three gain sets (not zones; cm848_selectCruiseGovernorGainSet), the bumpless transfer flag,
  cruise_pid_proportional / integral / derivative / integral_acceleration_gain (were kp / ki / kd /
  rate_integral _working), the speed error / after droop, the external reset and the rate limit preset
  flags (were cruise_confirm_flag_a / _b), the speed error gain (e2m Cruise_RSG_Gain_Auto) and the gear
  ratio gain (Cruise_RSG_Gain_Adj, with its table), the preset fueling window and the sump (e2m
  Cruise_RSG_Sump_*: fuel held outside the integrator; were rate_correction / fuel_demand_delta).
- The cruise speed command: cm848_increaseCruiseSpeedCommand / cm848_decreaseCruiseSpeedCommand (were
  cm848_protectionFuelRateRamp / Step) with cruise_accelerate_ramp / cruise_coast_ramp /
  cruise_bump_up_step / cruise_bump_down_step / cruise_minimum_coast_speed / cruise_minimum_set_speed
  (e2m 118F, were protection_fuel_rate_* / cruise_speed_*_cal); cruise_resume_speed; the power-off set
  speed save / restore (were cm848_initFuelRateFromCapability / cm848_validateFuelRateTarget).
- CRUISE_CONTROL_STATE members from the e2m value list 'off/set/resume/coast/accel/bump down/bump
  up/hold/cancel': CRUISE_COAST / CRUISE_BUMP_DOWN / CRUISE_BUMP_UP / CRUISE_HOLD / CRUISE_CANCEL (were
  DECELERATE / DECELERATE_2 / ACCELERATE_2 / ACTIVE_HOLD / STANDBY).
- cm848_secondOrderFilterUnsigned (was cm848_interpolateTableLinearStep): a second order filter that
  returns 0 in this build (asm: two srwi 16).
