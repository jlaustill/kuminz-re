cm848: round 43 stage A - cm848_computeFuelRpmCompensatedOffset is the main injection end of injection timing

The function computes main_injection_timing_copy - (main_injection_pulse_width + addend) x average_engine_speed x 6 /
1e6 x 256 / 600.
- **The units:** on-times are 0.4 us per count and the speed is 1/8 rpm. So the subtrahend is the pulse's crank angle
  in main timing counts (0.1171875 deg), and the result is where the main injection ends.
- **Renames:**
  - the function -> cm848_calculateMainInjectionEndTiming;
  - its output fuel_rpm_compensated_offset -> main_injection_end_timing;
  - its four calibrations (round 39's fuel_rpm_compensated_offset_* names) -> main_injection_end_timing_default /
    _pulse_width_addend / _upper_limit / _lower_limit.
- **Types:**

  - The addend (lhz) and the output stay word. cm848_updateOilChangeMonitor loads the output with lhz and reads it
