cm848+cm550: round 72 stage A - lookupApplicationMemoryRegionType is one function in both firmwares; CM550's region codes become MEMORY_REGION_TYPE (was MEMORY_ACCESS_FLAG) and its table is typed

The application memory region lookup is the same function in CM848 (0x50d784) and CM550 (0x3460e). Both bodies:
- compute end = start + length - 1 (CM550 returns 9 when it wraps);
- scan the table for an entry with entry.start <= start and end <= entry.end;
- return the entry's byte +8 when the mode flag is 1 (CM848 development_mode / CM550 the byte at 0x80de30), else its
  byte +9;
- return 9 when no entry holds the range.

CM550's table at ROM 0x345dc has 5 x 10 bytes, and the lookup's code follows it at 0x3460e. It holds CM848's codes:
- main flash 0x0-0x7ffff 4/4;
- RAM 0x800000-0x8091dc 3/3;
- extended RAM 0x8091dc-0x80ffff 0/0;
- EEPROM 0x1000000-0x1001fff 5/5;
- registers 0xffc800-0xffffff 3/10.
CM550 has no Bank 2. The twins share one unprefixed name, as the stage 9b twins do.
