cm550: round 94 stage A - one sign rule for round 93's typed rows; the EEPROM image is 4 KB in the address tool

Sign rule. Round 93's two typing passes decided signedness differently: pass 1 by the code's casts, pass 2 by
Calterm's flag alone. One rule now, applied to every typed row (sign_rule_r94.py, both_views_r94.py):
- the code decides when its uses agree. A row typed unsigned shows its signed uses as (short) / (int) casts and its
  unsigned uses plain; typed signed, the reverse - so both renders are needed, and a cast that only packs a byte into a
  message ((char)((ushort)x >> 8)), builds a fixed-point value ((uint)(ushort)x << 0x10) or truncates an addition is
  not a use (cast_contexts_r94.py);
- mixed uses, or none, leave it to Calterm's S / U flag; with no plain record, unsigned.
