**Trip / lifetime counters (2026-11-12, PR #46 — renamed):** `cm848_updateTripAndLifetimeCounters` (0x523148, was `j1939FuelDemandProcessing`) runs in 2 of the 40 main-loop phases (~100 ms if a phase is one 5 ms PIT tick — unconfirmed) when bit 13 of `algorithm_enable_flags_40_cal` (0x3fd5ec, EEPROM 0x16a = 0x27EF here; was a second `governor_system_config_flags`) is set. SCI command 35 (`cm848_sciCommand35Callback` -> `trip_counters_reset_pending_flag`) clears the trip set. Lifetime / trip pairs (EEPROM offset): distance pulses `lifetime_distance_pulses_cal` 0x8ea / the trip dword at 0x3fee28 = 0x19a6; engine-run passes `lifetime_engine_run_time_cal` 0x19de / `trip_engine_run_time_cal` 0x19f2; idle passes (`engine_idling_flag`: the low speed governor fueling state 11 within +/-400 counts = 50 rpm of its reference; e2m 117F +A names the fuel twin Total_Idle_Fuel_Used) `lifetime_idle_time_cal` 0x19da / `trip_idle_time_cal` 0x19ee; fuel `lifetime_fuel_used_cal` 0x19d6 / `trip_fuel_used_cal` 0x19e6; idle fuel `lifetime_idle_fuel_used_cal` 0x8f4 / `trip_idle_fuel_used_cal` 0x19ea; `trip_average_fuel_economy_cal` 0x8f2 (distance x 13603 x 8 / (trip_fuel_used_cal x 8000) — reproduces the stored 94 / 90 = 9.4 / 9.0 mpg, so one fuel count is about 1/10882 gallon). Fuel source: `injected_fuel_running_total` (was `crank_period_running_total`) gets every injection's quantity added from the TPU-A channel 6 injection interrupt; the counters take its delta >> 12 at each PCI 0x5D send. **HP Tuners zeroes all of them** (older dump: 13,044,913 pulses = 1,631 mi, 3,196,806 engine-run passes; before-HPT dump: 1,448,503 = 181 mi; after HPT: 0). **PGN 65248 Vehicle Distance (on-request responder `cm848_j1939HandlePgn65248VehicleDistance`) reports `lifetime_distance_pulses_cal` / 8000 x 12.874752 as total vehicle distance** — the decompiler shows its 64-bit divisor 8,000,000,000 truncated to 0xdcd65000 — so a J1939 ELD sees this wiped ECM counter, not the cluster odometer; the trip field source (0x3fdd70) is never written. PCI 0xDF byte 1 = `lifetime_distance_pulses_cal` >> 22. No responder is registered for PGN 65253 (hours), 65244 (idle) or 65257 (fuel). **Still mis-typed:** RAM 0x3fee08-0x3fee2f is time-shared — during boot it is the boot ROM's own EEPROM-header shadow (`eeprom_shadow_header`, whose `config_dword` holds the runtime counter loaded from EEPROM 0x30), afterwards the app's mirror of EEPROM 0x1986-0x19ad — so the trip distance dword still renders as `ram0x003fee28`. The boot-time use goes on past 0x3fee2f: `mpc555_eepromValidationCycle` counts in the dword at 0x3fee34, `cm848_lookupEepromParameterAddress` returns 0x3fee38 and `cm848_bootSciCheckSecurityKey` reads the bytes 0x3fee3a-0x3fee3d, while the application keeps its oil change monitor there (EEPROM 0x19b2-0x19bb) - retyping those words for the application made the boot code worse (2026-11-16), so they keep their types.
