## Verified findings

- 0x186ae == CM848 0x507d50 instruction for instruction (params configuration, state, history, selector; offsets 2/4 6/8 config, 6/8 state, 0/2 history; unsigned compares; cap 0x100). Callers 0x18e94 (speed limit loop) and 0x19790 (fuel limit loop). TWIN.
- 0x18708: (x-min)<<8 / (max-min) divs.l, clamp 0..0x100; NO x==min check and no division helper (CM848 0x507dc0 returns 0 when x==min and calls cm848_clampedDivisionWithBounds) -> counterpart. Callers 0x18c74 (restart severity indexes), 0x197b8 (fuel limit loop).

Identical unnamed stubs at 0x19ca0 0x1a1d6 0x1a73c 0x1a950. Vector 66 = 0x46906 (undumped), so an installer above 0x40000 cannot be ruled out.
- 0x18968 (past threshold, params config, state, is_engine_speed, select): switch input (flags 0x30) -> 1 when ((*input & mask) != 0) == (flags & 0x10 != 0); analog: select 0 -> *state+0xA (fuel) / *state+0x12 (rpm); 2 -> config+0x10 / +0x12; 3 -> config+0x20 / +0x22; flags 0x4 -> input >= threshold else input < threshold, UNSIGNED (bcs/bcc).
