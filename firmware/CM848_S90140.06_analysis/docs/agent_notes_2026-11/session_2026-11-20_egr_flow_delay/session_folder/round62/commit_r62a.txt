  get parameters by ID, and 4 / 5, disable / enable broadcast.
- j1939_diag_request_batch_44to49 -> cm848_registerJ1939MemoryWriteServices (0x44 / 0x45 / 0x4b / 0x4d / 0x47 / 0x49).
- j1939_diag_request_batch_43to48 -> cm848_registerJ1939MemoryReadServices (0x43 / 0x4a / 0x4c / 0x46 / 0x48).

- j1939_pgn_handler_init_batch -> cm848_registerJ1939InputMessageHandlers: the six j1939_receivePgn<N>Handler input
  handlers, and it starts the delay below.
- cm848_initJ1939Dm1RequestHandler -> cm848_registerJ1939Dm7Handler: it registers the PGN 58112 (DM7) handler.

Globals:
- j1939_dm1_request_mode_byte -> j1939_dm7_test_identifier: DM7's first byte is the Test Identifier, SPN 1224 (from
  the local J1939 database). 0 answers with the intake air heater monitor result and 1 with the misfire monitor result
  (DM8).
- governor_table_check_startup_delay -> j1939_input_fault_start_delay: set to 1000 at registration and counted down
  by cm848_tickJ1939InputSupervision. While it is nonzero, the J1939 input processors clear their data error and
  timeout faults instead of setting them.
- the pedal fault mode engine speed filter state and its ROM coefficient (two type-only rows named);
