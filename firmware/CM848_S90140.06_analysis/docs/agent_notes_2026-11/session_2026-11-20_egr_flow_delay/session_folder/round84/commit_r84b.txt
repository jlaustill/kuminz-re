- The boot block image (ROM 0x291F4-0x2CE63) is data. cm550_updateBootBlockFromImage programs it into flash at 0,
  and no real code calls into it: prefix_rule_check.py finds only other image copies referencing the nine copies.

- tpu_microcode_image is dword[419] again: the 0x68C bytes mc68k_loadTpuMicrocode copies, up to

  mc68k_hardwareInitAndStartup read 0x311F4 / 0x31256, the image's PC-relative view of ROM 0x8000 / 0x8062.

  MC68336-specific code takes the mc68k_ prefix (docs/superpowers/specs/2026-03-17-cross-firmware-convergence-
