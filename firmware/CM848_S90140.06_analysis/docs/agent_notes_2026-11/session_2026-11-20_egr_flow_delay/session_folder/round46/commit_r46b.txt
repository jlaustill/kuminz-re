cm848: round 46 stage B - the park / neutral exit engine speed limit is rock cycle torque management (e2m 8C2A / 8C49-8C4B)

Three e2m blocks name the family:
- Its enable bit was already algorithm_enable_flags_43_cal.rock_cycle_torque_management_enable (e2m 106B).
- 8C49 (in the dumped parameter ID table) RE_RCTM_* holds the window function's enabling calibrations ("rock cycle
  torque mgt. speed derate"). 8C4A / 8C4B hold its transmission temperature dwell table.
- 8C2A (past the table; a field match of 6 / 6 records) TC_Rock_Cycle_* holds the speed limit function's
  calibrations: "engine speed to send HSG during rock cycle derate" (850 rpm), the commanded throttle window, the
  maximum road speed, the ramp rate and the active-too-long time.
- 8A7C +8 TC_Rock_Cycle_Flag / +A RE_RCTM_Timer hold the active flag and the dwell countdown.

The trigger stays in the plates. While the park / neutral switch is set with the throttle and the output shaft speed
in range, a dwell is loaded from the transmission temperature. Once the switch clears, the engine speed is held at
850 rpm until the dwell runs out, then ramps back.
