updates), ordinals (cm848_periodicTaskGroup12_calibration1 ...), snake_case phase names
(cm848_phase_common_processing / cm848_phase_group_a_processing / _b_processing) and one orphaned twin name
(periodicTaskSet_fuelDemand; CM550's task set took its slot name in round 93).

  order; an older plate stays as '| earlier note:'.
