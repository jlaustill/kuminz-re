cm848: wave 15 stage 10c - low_speed_governor_gain_set_t, the dword splits, byte / dword / i32 widths; docs

The types the wave's reports and the main session's width census settle (every access counted with
width_census.py over both banks):
- low_speed_governor_gain_set_t {short proportional_gain, integral_gain, derivative_gain, jerk_gain} on
  the six 4-word sets the gain state selects: default (10EC), aggressive (10EE +12), middle / high gear
  (10EA +14 / +C), override (10ED +C, was governor_j1939_speed_target) and TSC1 (10EB, was
  j1939_low_speed_governor_proportional_gain); the member rows of the default and override sets go; the
  two gain set pointers are low_speed_governor_gain_set_t *. cm848_loadLowSpeedGovernorGainSet now reads
  low_speed_governor_gain_set_pointer->proportional_gain ... with no cast.
- 0x3ffcaa dword -> i16 and 0x3ffcac named wastegate_duty_engine_brake_lower_limit (16A1 +12 / +14,
  both lha; it rendered as ._2_2_ of the dword).
- 0x3ff69c dword -> all_speed_governor_deadband_compensation_flag + 0x3ff69e
  all_speed_governor_deadband_delta_decrement_rate (107D +16 / +18, both lhz).
- 0x40a042 word -> byte and 0x40a043 supervisor_chip_overspeed_consecutive_occurrence_count (11AE +A / +B,
  1-byte records, lbz): the old word render read the count as (byte)targets_per_revolution.
- 0x409530 word -> byte (lbz); the 4-byte encryption seeds 0x3fdd86 / 0x3faa88 -> dword (lwz; they
  rendered with _); the ASG QI / QP adjustments 0x40a1cc / 0x40a1d4 -> i32 (signed 4-byte records).

Proof: after reversing the six labels, six functions differ, each by exactly the intended rendering
(cm848_loadLowSpeedGovernorGainSet, cm848_selectLowSpeedGovernorOverrideGainSet,
cm848_runOperatingModeSpeedGovernor, cm848_calculateEffectiveFuelLimit,
cm848_calculateWastegateDutyRequest, cm848_sendPgn56320AntiTheftStatus), plus the two byte renders in
cm848_configureSupervisorChip and the fuel pressure monitor. Warnings unchanged; the retyped rows now
match their e2m widths. (Struct fields take short, not i16: a first build with i16 gave a 2-byte array
field.)
