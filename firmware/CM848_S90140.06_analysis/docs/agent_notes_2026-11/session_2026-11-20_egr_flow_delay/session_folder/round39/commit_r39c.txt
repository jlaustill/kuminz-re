cm848: round 39 stage C - the last 42 HARD _cal rows renamed from their code, the supervisor chip block re-domained

audit_cal_suffixes.py's HARD list drops from 42 to 0: no _cal name is left outside the EEPROM mirror
(0x3fd482-0x3feec1).
- **Why _cal goes:** 39 of the rows sit in the 0x40xxxx calibration block, which is a ROM copy: each dump word
  equals ROM at RAM - 0x39a3e6. The code writes none of the 42.
- **39 names now come from their code use.** 11 of them also match the e2m record that the parameter ID table
  resolves at the address. Each record was checked against its code use, because record offsets can drift between
  the 11.45 e2m and the truck's 11.46.06. Examples:
  - all_speed_governor_minimum_speed_offset (107B +8 ASG_Min_RPM_Offset, was governor_speed_lower_limit_offset_cal);
  - wastegate_duty_proportional_gain_rate_limit (16A1 +A C_TGC_P_Gain_Rate_Lim, was governor_rpm_error_gain_cal);
  - turbocharger_speed_estimate_boost_lead_gain (18CC C_TSE_Boost_Lead_Gain);
  - low_speed_governor_exit_fuel_hysteresis (11A3 +2 Fuel_Hysteresis);
  - cylinder_balance_delta_speed_threshold / _upper_speed_limit / _lower_speed_limit / _motoring_fuel_threshold
    (81AE CBD_*, were fuel_demand_zero_rpm_* / cylinder_sync_*);
  - cam_pulse_count_with_added_tooth (8194 +2) and low_speed_filtering_threshold (8194 +28);
  - equivalent_throttle_tracking_proportional_gain (81A9 +2, next to the named integral gain).
